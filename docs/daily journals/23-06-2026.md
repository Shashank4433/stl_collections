## Problem Encountered

While the implementation worked correctly for primitive data types, issues were observed when testing with:

```cpp
DynamicArray<std::string>
```

The program compiled successfully but failed to produce expected output during execution.

Investigation revealed that low-level memory allocation techniques were not properly managing object construction and destruction for complex types such as `std::string`.

---

## Analysis and Learning

During debugging and research, the following concepts were studied:

* Template implementation requirements in C++
* Object lifecycle management
* Constructor and destructor behavior
* Deep-copy semantics
* Differences between C-style and C++ memory management
* Handling non-trivial object types within generic containers

Key observations:

* Raw memory allocation only reserves memory.
* Constructors and destructors are not automatically invoked with C-style allocation.
* Complex objects require proper construction, copying, and destruction.
* Generic containers must support both primitive and object data types safely.
