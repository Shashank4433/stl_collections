## Summary

Today's development work focused on completing the implementation of the `HashMap<K,V>` template container. ## Challenges Faced

### Collision Handling

Maintaining linked-list integrity during deletion required careful pointer updates.

Special attention was needed when:

* Removing the first node in a bucket.
* Removing nodes from the middle of a chain.
* Removing the last remaining node.

### Rehashing

During resizing:

* Old bucket indices became invalid.
* All nodes had to be reinserted using the new capacity.
* Existing key-value pairs needed to remain accessible after redistribution.

These issues were resolved through systematic testing and validation.
